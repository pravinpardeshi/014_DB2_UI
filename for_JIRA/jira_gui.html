How auth works (read me if token exchange fails)
  1. Click Open Atlassian Authorization Page, approve access.
  2. Browser lands on http://localhost:8000/callback?code=… — if nothing listens, it shows “unable to connect”. That is OK: copy the code from the address bar into the box above.
  3. Click Exchange code for tokens. Browsers often get blocked by CORS on auth.atlassian.com/oauth/token. If so, use one of the generated snippets below (Python / curl) once, then paste the tokens back here.
  4. Alternative (easiest): run python testJIRACloud.py once — it writes jira_token.json. Open that file, paste access_token above, click Discover site.
